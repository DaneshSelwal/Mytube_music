## 2026-10-06 - LrcParser Regex Instantiation
**Learning:** Instantiating `Regex` inside a function called frequently or inside a loop has significant overhead. Replacing `Regex` with manual string parsing for highly predictable formats like LRC timestamps (`[mm:ss.xx]`) significantly improves parsing speed and reduces allocations. Pre-allocating `ArrayList` size further improves it.
**Action:** When parsing LRC files or similar structured formats, use manual character indexing (`line[startIdx + 1] - '0'`) instead of Regex. In general, avoid compiling Regex per method call and avoid substring allocations if possible.
