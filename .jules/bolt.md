## 2024-06-25 - [LRC Regex parsing overhead]
**Learning:** Extracting regexes out of functions doesn't resolve all string processing overhead. Replaced the `Regex` implementation for timestamp parsing entirely with manually traversing the string characters for predictable LRC formats (e.g., `[mm:ss.xxx]`).
**Action:** When a string format is strictly structured (like LRC line items), bypass `Regex` and use character checking and math via char codes (`(c.code - '0'.code)`) to significantly reduce processing and garbage collection overhead. Pre-allocate arrays like `ArrayList<T>(lines.size)` to avoid continuous re-allocation when `lines.size` is known. Avoid using `trim()` by scanning `whitespace` bounds using `isWhitespace()`.
